# 环肽 Ensemble 工作流

## 1. 适用范围

本文件描述环肽 docking/后续模拟的通用构象 ensemble 方法，不替代具体任务 README，也不把一次任务参数提升为稳定默认值。

目标是交付化学正确、来源可追溯、非冗余且覆盖主要构象差异的候选集合，而不是用单个最低瞬时能量结构代表全部状态。

## 2. G0：冻结化学真值

在运行前冻结序列、立体化学、环化方式、端基、质子化微状态、净电荷、目标温度和下游格式。

环化可能是二硫键、头尾成环、侧链成环或其他连接；拓扑、原子命名和连接证据必须明确。不得以 AF3、视觉或 `pdb2gmx` 的自动猜测替代化学真值。

输入清单记录来源文件、分子图或序列、连接、预期原子和 SHA-256。若上游结构存在手性或连接疑点，先重建并验收，再进入 GROMACS。

## 3. G1：起点与 pilot

从不同构象簇或不同几何起点选择代表，避免只取单一排名结构。新力场、新版本或新体系先选择一条肽做端到端 pilot：拓扑、EM、短 NVT/NPT、短生产、PBC 处理、读取和 QC 全链路走通。

pilot 要记录输入、attempt、版本、命令、资源、日志、最终步数、约束/LINCS 状态、闭环几何、手性和碰撞检查。pilot 通过只表示该协议和范围可运行，不表示采样收敛。

## 4. G2：拓扑与阶段

在拓扑审计中确认：

- 预期闭环键恰好存在且价态正确；
- 不存在非预期头尾键或断键；
- 端基、质子化和净电荷符合冻结定义；
- 预期角、二面角和约束项存在；
- 原子映射、残基命名和水/离子组成可追溯。

阶段可按体系需要采用化学重建、位置约束 EM、逐步平衡、无约束 EM、短 NVT/NPT 和无约束生产。每一步创建独立 stage 产物，不覆盖上一阶段。

不要用 `-maxwarn` 绕过未知拓扑或化学错误。warning 必须逐条归类、记录和验收。

## 5. G3：多起点采样

正式采样由 manifest 驱动，每个起点、随机种子、attempt、远程输出前缀和日志唯一。所有序列若要比较，应尽量使用同一协议；协议差异必须显式记录。

保存间隔、总时长和重复数由 pilot 与科学目标决定。多起点可以增加构象覆盖，但不能自动证明热力学收敛；不得用单轨迹 RMSD 平台作唯一收敛证据。

轨迹和 checkpoint 远程保留。不得为了本地分析把全部长期轨迹放入工作区；分析时按文档下载到临时目录。

## 6. G4：PBC、抽样与聚类

优先在远程生成可验证的 PBC 修正或按需导出帧，并保留源轨迹不变。分析 replay 记录选择组、居中、`pbc` 模式、拟合、丢弃时间和抽样间隔。

聚类应在同一化学定义和明确原子选择上进行。可先按主链和闭环相关原子聚类，再检查侧链取向、氢键、盐桥、芳香堆积、暴露度和紧致度。

代表结构必须是实际轨迹帧的 medoid 或可追溯真实帧，不使用未经说明的平均坐标。构象数量由簇分布和质量门禁决定，不足时如实交付，不复制近重复结构凑数。

## 7. G5：质量门禁

候选至少检查：序列、原子数、闭环连接、键长/角度、端基、净电荷、全部指定手性、严重碰撞、拓扑映射、阶段状态和来源追溯。

用于 docking 或其他下游前，还要验证目标软件导入回读不会删除闭环键、添加错误氢、改变端基或重新编号导致来源丢失。

建议状态：`CANDIDATE`、`NEEDS_REBUILD`、`VALIDATED`、`READY_FOR_DOCKING`、`REJECTED`。状态必须有逐项 QC 和 manifest 证据。

## 8. G6：交付

交付包使用白名单，至少包含结构、构象 manifest、质量报告和 SHA-256 清单。每个结构关联：任务、attempt、分析、起点、轨迹、帧号、构象簇、处理方法、质子化和状态。

`READY_FOR_DOCKING` 不等于最低能构象、全局最优结合构象或自由能结论。ensemble 的科学边界、采样时长、簇人口和未覆盖空间必须写入 README。

## 9. 本地数据规则

轨迹只在远程必要保留；本地聚类和验证所需临时文件仅放：

```text
D:/Temp/GROMACS/<task_id>/<analysis_id>/
```

报告、manifest、图表和小型抽样结果写回任务逻辑根，临时轨迹在验证后按批准策略清理。所有结果可通过 replay 找到远程源文件。

## 10. 已知边界

不同闭环化学、力场、GROMACS 版本、质子化方案和 docking 软件的行为不能互相推断。未完成 pilot 的组合按 C 或 TODO 标记；版本升级、拓扑变更或下游格式变化后重新验证。
